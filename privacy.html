Privacy Policy

Applies to: gptx-colab-cache (the "application"), a personal tool for a single developer.

Data accessed

The application requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. With this scope it can see and modify only the files and folders that the application itself created in the authorizing account's Google Drive. It cannot access any other file.

Data collected, stored and shared

  • The application does not collect personal information.
  • The application does not send any data to the developer or to any third party other than Google, whose APIs it calls to read and write its own files.
  • The OAuth credentials (client ID, client secret and refresh token) are stored only on the developer's own computer and in the developer's own temporary computing environments, and are not published or shared.
  • The application does not use data for advertising, analytics, or for training machine-learning models.

Retention and deletion

Files created by the application live in the developer's own Google Drive and can be deleted by the developer at any time. Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

This policy may be updated; the current version is always at this address.
