gptx-colab-cache

gptx-colab-cache is a small personal tool used by a single developer to move their own working files (for example, software environment archives and model weights) between their own computers and Google Colab runtimes through the developer's own Google Drive.

What it does

  • It uses the Google Drive scope drive.file, which allows access only to files and folders that this application itself created.
  • It does not read, list, or modify any other file in the Google Drive account.
  • It is not offered to other users and has no sign-up, no website back end, and no user database.
